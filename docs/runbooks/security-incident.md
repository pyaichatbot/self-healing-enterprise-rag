# Runbook: Security Incident

## Trigger
- Confirmed or suspected data exposure
- Credential leak or unauthorized access
- Malicious prompt injection campaign with impact

## Response
1. Declare incident and assign incident commander.
2. Contain: revoke keys, isolate workloads, block bad actors.
3. Preserve evidence: logs, traces, snapshots.
4. Eradicate and recover using approved playbook.

## Communication
- Notify security and executive stakeholders.
- Track timeline, impact, and decision log.

## Post-Incident
- Complete RCA within 5 business days.
- Ship corrective actions with owners and deadlines.
