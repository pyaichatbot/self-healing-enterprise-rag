# Runbook: On-Call Handoff

## Handoff Checklist
1. Active incidents and current severity.
2. Open alerts and known noisy monitors.
3. Temporary mitigations currently enabled.
4. Pending deploys, rollbacks, or risky changes.
5. Stakeholder comms status.
