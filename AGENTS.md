# AGENTS

## Scope
This subproject hosts infrastructure, operational docs, and test scaffolding for the self-healing RAG service.

## Ownership
- `docs/`: policy, architecture, and runbook documentation.
- `ops/`: observability and deployment placeholders.
- `tests/`: baseline test categories and smoke checks.
- CI bootstrap in `.github/workflows/`.

## Working Rules
- Keep docs executable and concise.
- Promote placeholders to implementation-ready artifacts as service contracts stabilize.
- Prefer additive changes; avoid deleting baseline governance sections.
